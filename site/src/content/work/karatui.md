A terminal user interface for [Karakeep](https://karakeep.app/). Built it because I got tired of clicking around the web UI when I wanted to organize my bookmarks.

Features:
- Load bookmarks from a particular list
- Add and remove tags and lists from bookmarks
- Tag and list suggestions based on existing bookmarks
- Open links from the terminal
